## VHS installation
1. Install [ttyd](https://github.com/tsl0922/ttyd?tab=readme-ov-file#install-on-linux)
2. Install dependencies `apt install libev-dev ffmpeg`
3. Install chrome
```
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
apt install ./google-chrome-stable_current_amd64.deb
```
4. Download [vhs](https://github.com/charmbracelet/vhs) and run `go build`
